# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/tkeehner/beacon/security/advisories/new)
("Report a vulnerability" on the Security tab). Include steps to reproduce,
the affected version, and any proof of concept.

You can expect an acknowledgement within about a week. Please give a
reasonable window for a fix before public disclosure.

## Supported versions

Only the latest release on `main` receives security fixes.

## Scope

In scope: the Beacon Android app and the optional `tools/beacon-pc` update
tool in this repository. Out of scope: third-party apps Beacon launches
(such as your digital assistant app) and any relay server you run yourself.
